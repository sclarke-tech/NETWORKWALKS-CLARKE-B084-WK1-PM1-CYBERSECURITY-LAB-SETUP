# NETWORKWALKS-CLARKE-B083-WK1-PM1-CYBERSECURITY-LAB-SETUP
Week 1 Networkwalks Cybersecuirty Internship project: Setting up a virtual cybersecurity lab using Oracle Virtual Box and Kali Linux.
##Project Overview 
This project documents my Week 1 hands-on cybersecurity lab for the Networkwalks Cybersecurity Internship. I worked with Oracle VirtualBox and Kali Linux to prepare a virtual environment for cybersecurity training. 

##Project Objectives 
- Setup virtual cybersecurity lab.
- Configure and access Kali Linux using Oracle VirtualBox.
- Troubleshoot Linux login and virtual machine issues.
- Documented the setup process and lessons learned.

##Tools and Technologies
- Oracle VirtualBox
- Kali Linux
- Windows host computer
- GNU GRUB bootloader

##Lab setup and Procedure
1. Opened Oracle VirtualBox on my Windows computer.
2. Reviewed the existing VirtualBox and Kali Linux environment.
3. Worked through Kali Linux virtual machine setup and configuration.
4. Attempted to login to Kali Linux and encountered a password issue.
5. Used the GRUB recovery procedure to reset the forgotten password.
6. Regained access to Kali Linux and continued working in the virtual environment.

##Troubleshooting 
**Issue: ** I could not login to Kali Linux because I had forgotten my password. The default credentials did not work. 

**Resolution: ** I used the GRUB boot process and Linux password recovery procedure to reset my password, then successfully logged back in. 

**Lesson Learned: ** Understanding Linux boot and recovery procedures is important for troubleshooting and system administration.
